# VR 기반 프로그래밍 언어 실행 과정 학습 도구

**2020년 제주 SW중심대학 사업단 산학 프로젝트**

## 프로젝트 소개

VR 환경에서 학습자가 **직접 컴퓨터의 역할을 수행하며 프로그래밍 언어의 동작 원리를 체험하는 교육용 시뮬레이션 도구**입니다.

학습자는 프로그램의 실행 과정에서 발생하는 입출력, 메모리 복사 및 이동, 연산 등의 작업을 직접 수행합니다. 이를 통해 코드가 실행되는 순서와 데이터가 처리되는 과정을 직관적으로 이해할 수 있습니다.

## 주요 학습 요소

- **입출력(Input/Output):** 프로그램 실행 과정에서 데이터의 입력과 출력을 직접 수행
- **메모리 조작(Memory Operations):** 데이터의 복사 및 이동 과정을 체험
- **연산(Computation):** 프로그램의 연산 명령을 직접 수행
- **실행 흐름(Execution Flow):** 코드의 명령어가 순차적으로 실행되는 과정 학습
